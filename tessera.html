Process

From first sketch to on-call.

A typical engagement runs in four stages. Scope and price are fixed at the end of the first one.

  • Weeks 0–2

    Discover

    Interviews with users and the people who run the current system. You get a written scope, a risk list and a price.

  • Weeks 2–4

    Prototype

    A clickable prototype in ten working days, tested with five real users before any production code is written.

  • Weeks 4–20

    Build

    Two-week increments with a demo every other Friday. Every merge is deployed to a staging environment you can open.

  • Ongoing

    Operate

    Monitoring, incident response and quarterly reviews. Or a documented handover, if you would rather run it yourself.
